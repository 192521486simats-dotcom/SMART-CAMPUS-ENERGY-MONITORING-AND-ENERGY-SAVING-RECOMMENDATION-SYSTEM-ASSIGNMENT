# Smart Campus Energy Monitoring and Energy-Saving Recommendation System

## Project Description

The Smart Campus Energy Monitoring and Energy-Saving Recommendation System is a C programming project designed to monitor and analyze electricity consumption across different campus facilities.

The system collects seven days of energy consumption data and identifies high-consuming and abnormal facilities. It also calculates energy savings, sustainability scores, and provides energy-saving recommendations.

## Features

* Seven-day energy monitoring
* Total and average consumption
* Highest and lowest consumption day
* Energy limit checking
* Abnormal consumption detection
* Facility searching
* Energy-based sorting
* Dataset merging
* Top energy-consuming facilities
* Sustainability scoring
* Energy-saving recommendations
* File handling
* Sustainability report
* Menu-driven interface

## How to Run

### GCC

```bash
gcc smart_campus_energy.c -o energy_monitor
```

Run using:

```bash
./energy_monitor
```

### Windows

```bash
gcc smart_campus_energy.c -o energy_monitor.exe
energy_monitor.exe
```
